Gerar e exportar
Imagens vêm da Replicate, que precisa do python serve.py rodando nesta máquina.

Gerar vídeo entrega um arquivo único com a narração embutida, pronto para subir no Shorts, Reels ou TikTok. É em tempo real: 30 s de vídeo levam 30 s, e a aba precisa ficar visível.

Baixar peças soltas não é vídeo — são os quadros em JPG, os MP3 e um timeline.json, para montar à mão no CapCut.
A Replicate só funciona com python serve.py rodando na sua máquina — pelo GitHub Pages a API dela bloqueia o navegador (CORS).
